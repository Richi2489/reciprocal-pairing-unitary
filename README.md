# reciprocal-pairing-unitary

Replication package for the preprint

**Ricardo A. López Pérez, *Reciprocal Pairing in Unitary Matrices with
Prescribed Diagonal Moduli*** — DOI
[10.5281/zenodo.22941170](https://doi.org/10.5281/zenodo.22941170).

The version cited by the preprint is the git tag `paper1-zenodo-v1`.

- `paper1-reciprocal-pairing/` — code, data, notes and the Lean 4
  formalization; see the README inside for what each file checks.
- Quick check of the statements of the paper:
  `cd paper1-reciprocal-pairing && python scripts/paper1_v2_check.py`
  (Python 3.11+, `pip install -r requirements.txt`; exit code
  0 means every check passed).
